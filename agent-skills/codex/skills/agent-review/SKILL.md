# Agent review

Give reviewers the verbatim request, instructions, and actual diff; split semantic, correctness, and verification lenses when useful. Reviewers are read-only unless assigned a fix. For an implementation task, apply confirmed high/medium findings and rerun affected checks; for a review-only request, report them without editing. Create no process ledger.

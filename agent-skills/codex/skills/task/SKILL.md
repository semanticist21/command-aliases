# Task

Read repository instructions/status, create one clean worktree from the current base, and preserve unrelated work. Make the smallest complete change, ask before conflicting/product/irreversible choices, run affected checks, and review the full diff. Stage explicit paths and land per the harness and repository policy. Remove only task-owned resources and report result, verification, landing, and survivors.

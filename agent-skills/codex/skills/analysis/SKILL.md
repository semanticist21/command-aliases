# Analysis

Lock the exact symptom and last known good boundary. Generate independent hypotheses across state, timing, data, environment, and interfaces; for each state a distinguishing prediction and cheapest falsifier. When one read cannot settle it, use independent investigators and a skeptic to refute the leading cause. Run read-only checks first, discard contradicted theories, reproduce the winner, and report cause, evidence, reach, and uncertainty. Do not fix unless asked.

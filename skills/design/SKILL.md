# Design

Start from the user's job and existing system. Show each fact/action once; create hierarchy with grouping, proximity, typography, and whitespace before decoration. Reuse platform/project controls, align related fields, preserve responsive/loading/error/empty/accessibility states, and avoid one-off styles or explanatory copy for conventional behavior. Inspect the rendered result at relevant sizes and interaction states.

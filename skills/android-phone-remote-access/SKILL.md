# Android phone remote access

Use only for an explicitly authorized phone. Verify the exact serial or hostname before taps, launches, installs, or logs. Never expose or forward ADB to the public internet, never guess wireless-debugging ports, and use an explicit serial when multiple devices appear.

Read [references/operations.md](references/operations.md) for USB bootstrap, trusted Tailscale/LAN transport, scrcpy commands, and recovery. Keep device identifiers, addresses, screenshots, logs, credentials, and app-specific recovery out of this public skill.
